# 架构说明

Copyright 2026 上海如静知华信息科技有限公司。

ZhuaTech EMS 采用前后端分离的模块化单体架构。Vue 3 同时承载桌面管理端和巡检员 H5；Spring Boot 提供认证、资产、计划、工单、巡检与备件 API；MySQL 保存业务数据，Flyway 管理数据库演进。

```text
桌面管理端 ─┐
             ├─ Vue Router / Axios ─ REST + JWT ─ Spring Security
巡检员 H5  ───┘                                  │
                                    领域服务 / JPA Repository
                                               │
                                         MySQL / Flyway
```

## 领域边界

- 资产域：唯一资产编码、分类、位置、责任人、价值、健康与运行状态。
- 维护域：周期计划、下次执行日期、维护班组和计划状态。
- 工单域：异常/状态/计划节能、优先级、派工、承诺时间和状态推进。
- 巡检域：巡检人员、完成时间、检查结果与现场发现。
- 备件域：编码、规格、仓库、现有库存和安全库存。

社区版以易理解和可运行优先。大型部署可将身份权限、流程编排、IoT 接入、文件服务、消息中心和报表分析拆分为独立模块或服务。
